# Roadmap

This roadmap is directional, not a release commitment.

## Phase 0

Desktop API feasibility, supported Shell implementation, and project skeleton.

## Phase 1

Reliable manual snapshot, compare, and restore with clearer recovery feedback.

## Phase 2

Multi-display-aware snapshot selection and explicitly designed coordinate remapping.

## Phase 3

Local automatic snapshot timeline with bounded retention.

## Phase 4

Tray UX, accessibility polish, packaging, and release engineering.

## Future

Potential CLI, restore preview, opt-in automatic restore, and portable storage mode. These remain exploratory and should follow evidence from the manual restore path.
